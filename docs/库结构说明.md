**2026-09-18 建。全部条目在 `B10.h5` 上实测过，不是查手册抄来的。**
**用途**：第 8 课软组织四核素、第 11 周锂包层 TBR、第 9 课 OpenMC 对拍时回来查。

> ⚠️ 凡标 **[推断]** 的，是我没有在数据上验证、只是按常理推的。**用到时自己核实**

一个核素一个文件，文件里按「温度 × 反应道」组织。**

```

    │   .atomic_weight_ratio = 9.926921          靶核质量 / 中子质量
    │   .metastable = 0                          0 = 基态
    │
    ├── energy                                ← 能量网格，每个温度一张
    │   ├── 0K     (940,)      ⚠️ 长度不一样
    │   ├── 250K   (941,)
    │   ├── 294K   (941,)
    │   ├── 600K   (941,)
    │   ├── 900K   (941,)
    │   ├── 1200K  (942,)
    │   └── 2500K  (942,)
    │
    ├── kTs                                   ← 各温度的 kT，单位 eV
    │
    └── reactions                             ← 58 个反应道
        └── reaction_051                      ← 名字就是 reaction_<MT 三位补零>
            │   .mt = 51
            │   .label = b'(n,n1)'
            │   .redundant = 0
            │   .Q_value = -718350.0

## 3. 每个量的物理含义

### 3.1 顶层属性

| 名字 | 物理含义 | B10 实测 |
|---|---|---|
| `A` | **质量数** = 质子数 + 中子数。整数 | 10 |
| `Z` | **原子序数** = 质子数。决定是什么元素 | 5（硼） |
| `atomic_weight_ratio` | 🔴 **靶核质量 ÷ 中子质量**。**注意它不等于 `A`** | **9.926921** |
| `metastable` | 是不是同核异能态（激发态长寿命核）。0 = 基态 | 0 |

> 🔴 **`awr = 9.926921` 而 `A = 10`，差 0.73%。**
> 因为：① 中子质量不等于 1 原子质量单位 ② 原子核有结合能亏损。
> **散射后算新能量的 `α = ((A−1)/(A+1))²` 里，那个 A 用的是 `awr`，不是整数 `A`。**
> 用 10 代替 9.9269 会让 α 错 0.1% 量级 —— 不报错，只是慢化算得略偏。

### 3.2 `kTs` —— 各温度的 kT

| 温度标签 | 实测 kT (eV) | `8.617333e-5 × T` |
|---|---|---|
| 0K | 0.000009 | 0 |
| 250K | 0.021543 | 0.021543 |
| **294K** | **0.025301** | 0.025335 |
| 600K | 0.051704 | 0.051704 |
| 900K | 0.077556 | 0.077556 |
| 1200K | 0.103410 | 0.103408 |
| 2500K | 0.215430 | 0.215433 |

`kT` 是**靶核热运动的特征能量**（k = 玻尔兹曼常数）。它决定自由气体展宽有多强。

> 🔴 **「0.0253 eV = 热中子」这个说法的出处就在这一行**：294 K 的 kT = 0.0253 eV。
>
> ⚠️ **两个要注意的**：
> 1. **294K 那一行对不上**：实测 0.025301，按 8.617e-5×294 算是 0.025335，差 0.13%。
>    真相是反的 —— **库是按 `kT = 0.0253 eV` 定的（室温惯例），反推 T = 293.6 K，标称写成 "294K"。**
>    **标签是四舍五入出来的，kT 才是真的。**
> 2. **0K 的 kT 是 9e-6 eV，不是 0** —— 那是个数值下限，不是物理。[推断]

### 3.3 `energy/<T>` —— 能量网格

- **单位 eV**（量级自检：1e-5 ~ 2e7。若是 MeV 会是 1e-11~20，若是焦耳会是 1e-24 量级）
- **严格递增**（全库 589 个文件 3900 个组合验过，零宽格 0 个）
- **入射中子的动能**，不是出射的

> 🔴 **每个温度的网格长度不一样**（0K=940、294K=941、2500K=942）。
> 多普勒展宽后共振峰变胖，NJOY 重构时需要的点数不同。
> ⚠️ **推论：`E` 和 `xs` 必须来自同一个温度。** 混用 294K 的网格配 600K 的截面，长度碰巧都是 941，
> `len(xs)+thr==len(E)` 这条判据**抓不住**，程序照跑，结果全错。

### 3.4 反应道的五个属性

| 名字 | 物理含义 |
|---|---|
| `mt` | **ENDF 反应类型编号**。国际标准，2=弹性，102=俘获，51~91=非弹到各激发态，600+=(n,p)，700+=(n,t)，800+=(n,α) |
| `label` | 人读的名字，如 `(n,a1)`。**字节串，用要 `.decode()`** |
| `redundant` | **1 = 它是别的道的和**，求总截面时必须跳过，否则重复计数 |
| `Q_value` | **反应能，单位 eV**。Q>0 放能，Q<0 吸能 |
| `center_of_mass` | **1 = 这道的角分布在质心系给**，0 = 实验室系 |

#### `Q_value` 实测与读法

| MT | label | Q (eV) | 物理含义 |
|---|---|---|---|
| 2 | (n,elastic) | **0** | 弹性散射不改变内能，动能守恒 |
| 51 | (n,n1) | **−718350** | 打到 B-10 **第一激发态 718.35 keV**。负号 = 要消耗这么多动能 ⟹ **这就是阈值的来源** |
| 102 | (n,gamma) | **+11456000** | B-10 吸收中子变 B-11，放出 **11.456 MeV** = B-11 的中子结合能 |
| 800 | (n,a0) | **+2789323** | ¹⁰B(n,α)⁷Li，Li 留在**基态** |
| 801 | (n,a1) | **+2311472** | ¹⁰B(n,α)⁷Li*，Li 留在**第一激发态** |

> 🔴 **两个 Q 值的差就是 BNCT 里那条著名的 γ 射线：**
> ```
> 2789323 − 2311472 = 477851 eV ≈ 478 keV
> ```
> **⁷Li 第一激发态退激发放出的 478 keV γ。**
> 临床上就是靠探测它来**在线监测中子注量**。
> **热能点 MT=801 占 93.6%，所以绝大多数俘获都走这条放 γ 的路。**
> —— 这一条 12 月可以直接讲，而且是从数据里看出来的，不是背的。

#### `center_of_mass` 为什么重要

- **MT=2、51 是 1（质心系）** —— 两体反应，角分布在 CM 系里才简单（低能 s 波下 CM 各向同性）
- **MT=102、800、801 是 0（实验室系）** —— 中子没了，谈不上"散射角"

> **第 11 周 14.1 MeV 读 MF=4 角分布时，抽出来的 μ 是哪个系的，由这个标志决定。**
> **读错系 ⟹ 出射能量全错，而且不报错。**

### 3.5 `<T>/xs` —— 截面本体

- **单位 barn**（1 barn = 10⁻²⁴ cm²）。量级自检：B10 热能点 3650 barn
- **它是微观截面 σ**，不是宏观截面 Σ。`Σ = N · σ`，N 是核子数密度（cm⁻³），换算要乘 `1e-24`
- `threshold_idx`：**这道的数据从能量网格第几个点开始存**

> 阈值反应在阈值以下截面恒为 0，存了也是浪费，所以**从阈值点才开始存**。
> ```
> len(xs) + threshold_idx = len(E)     ← 必然成立，这是一条判据
> ```
> 🔴 **不对齐不会报错，只会把高能区的截面贴到低能区。**
>
> **阈值随激发能级单调升高，`len(xs)` 单调变短**（实测）：
> ```
> (n,n1)  thr=582  len=359
> (n,n2)  thr=625  len=316
> (n,n35) thr=938  len=3      ← 只剩最高能那三个点
> ```
> **这不是存储技巧，是物理**：激发到越高的能级，需要的入射能量越高。

### 3.6 `product_0` —— 出射粒子

**只有"中子还活着"的道才有 `product_0`。** 实测 MT=205、207 没有这一层 —— 中子被吸收了。

| 名字 | 物理含义 |
|---|---|
| `yield` | **产额**：一次反应放出几个该粒子。MT=51 是 1（一进一出）。`(n,2n)` 会是 2 |
| `distribution_0` | **出射粒子的角度/能量分布** |
| `distribution_0.type = uncorrelated` | 🔴 **角和能不相关，可以分开抽样**。相关的话要抽联合分布，贵得多 |
| `angle/energy` (74,) | 74 个**入射**能量点，角分布在这些点上给 |
| `angle/mu` (3, 2203) | 🔴 **角分布表本体 = ENDF 的 MF=4** |
| `applicability` | 这个分布在什么能量范围内适用 |
| `energy`（空） | **[推断]** 两体反应的出射能量由运动学定死，不需要单独存表，所以是空的。**第 11 周用到时自己核实** |

> 🔴 **`angle/mu` 就是讲义说的「MF=4 角分布没有闭式 CDF，逆变换法用不了 ⟹ 只能用舍选法」的那张表。**
> **14.1 MeV 锂包层必须读它。白板题⑧ 练的舍选法就是为这个。**

**58 − 10 = 48 个叶子道。**

### 四类冗余道，性质不同

| 类 | MT | 是什么 |
|---|---|---|
| **真·求和节点** | 4 / 103 / 105 / 107 | 是同类子道之和。4=Σ(51..85)，107=MT800+MT801 |
| **粒子产生截面** | 203 / 204 / 205 / 207 | **产额加权**，不是反应道。`X` = "任意路径产生的"。**MT=205 算 TBR 时是主角** |
| **根本不是截面** | 301 / 444 | KERMA / 损伤能，单位 **eV·barn**。实测 9.12e9 和 6.36e7 |

> 🔴 **量级判据的现成示范**：MT=301 是 9.12×10⁹。世界上最大的共振峰也就 10⁵~10⁶ barn。
> **不用懂 KERMA 是什么，光看那个数就知道它不能往截面里加。**

### 🔴 一条编码纪律

> **代码里永远读 `redundant` 属性，绝不硬编码一张"这些 MT 要跳过"的列表。**
>
> 证据在同一张表里：**MT=104 在"总和类"号段里，但 `redundant=0`** —— 因为这个文件没存 650–699，它自己就是叶子。
> **树的形状由这个文件存了什么决定，不由 MT 号决定。**
> 换核素、换库版本，硬编码的列表会**安静地算错，不会报错**。

## 5. 三条已经在数据上验过的恒等式

```
MT=107  3895.7440  =  MT=800 245.3702 + MT=801 3650.3740    ✅ 精确（2026-09-15）
MT=105  0.00683616 =  MT=700 0.00683616                      ✅ 逐位
MT=103  0.000573582 = MT=600 0.000573582                     ✅ 逐位
```

> **判据的三个层级**：① 查手册（弱）→ ② 读文件的 `redundant` 标志（中）→ **③ 在数据上验（强，谁都糊弄不了）**

## 6. 全库扫描结果（2026-09-18）

```
589 个文件、约 3900 个 (核素,温度) 组合
能量网格点数        309 ~ 382389
零宽格 E[k]==E[k+1] 0 个
非单调 E[k]>E[k+1]  0 个
```

**所有网格严格递增。** 这就是零宽格约定选「插值入口 assert」而不是「建表时合并」的依据 ——
合并逻辑会是一段**永远不执行的代码**，而死分支里的 bug 是隐形的。
