## 2. 接口契约

新建 `mcstat.py`，放在 `my_code\` 下（和 lesson 文件同目录，`import mcstat` 才找得到）。

模块里**只放函数，不放任何顶层的计算和打印**——除了第 5 节说的自测块。

### 2.1 `mean_se(s, sq, n)`

给定累加量，返回统计三件套。

| 参数 | 含义 |
|---|---|
| `s` | Σx（一次幂的和） |
| `sq` | Σx²（平方和） |
| `n` | 样本数 |

返回 `(mean, var, se)`：`mean` 是样本均值，`var` 是**贝塞尔修正的样本方差**（分母 n−1），`se` 是均值的标准误。

**里面必须有一条 assert。** 想清楚：这个函数最可能被怎么用错？（提示：你 9/4 犯过 —— `x_var` 用了 `r` 的均值。这个函数拦不住那种错。那它能拦住什么？往 `n` 和 `var` 的取值范围上想。）

### 2.2 `dev_sigma(meas, ref, se)`

返回 `(meas - ref) / se`。

一行的函数值得单独抽出来吗？值得，理由在 2.3。

### 2.3 `row(name, meas, ref, se)`

打印一行表格。格式**原样照抄 `lesson04_energy.py` 里现有的 `row`**：

```
"  %-12s %14.6f %16.6f %11.2e %+10.2f"
```

⚠️ **一个字符都不许改**，否则 diff 立刻不为空。
（想改格式？可以，但那是**第二次**提交的事。**一次提交一件事**：这一轮只搬，不改。）

### 2.4 `header()`

打印表头那一行。同样照抄。

### 2.5 `chi2_uniform(counts, expected)`

返回卡方统计量 `Σ (counts[k] − expected)² / expected`。

`expected` 是标量（每箱期望数相同）。

**这个函数里也要有一条 assert，而且这一条比 2.1 那条值钱。** 提示：卡方检验有一个前提条件，你 9/4 用 M=20、N=1e6 时它轻松满足，但第 7 课检验 Maxwell 谱时**分箱一多就会破**。破了的话卡方分布这个近似本身就不成立，判据静默失效。**查一下那个条件是什么，写成 assert。**

### 2.6 `check(name, meas, ref, se, k=3.0)`

组合拳：`row(...)` 打印，然后 `assert abs(meas-ref) < k*se`，消息里要带上实测值、参考值和偏差的 σ 数。

⚠️ **注意顺序：先打印，后 assert。** 9/5 的教学点——**调试最需要数字的时刻恰恰是失败的时刻**。

⚠️ **这个函数只适用于双边统计检验。** 4b 的超越量普适界是**单边物理界**，不能用它（9/5：`abs()` 不是永远要加）。所以 4b 那条留在 lesson04 里手写，不要硬塞进 `check`。**能抽的抽，不能抽的不抽 —— 判断哪些不能抽，比抽出来更难。**

## 3. 🔴 你一定会撞上的那个坑（提前说，因为它是本次最值钱的一条）

两个文件里的标准误，**代数上相同，写法不同**：

`lesson04_energy.py`：
```python
var = N/(N-1)*(sq/N - mean**2)
se  = math.sqrt(var/N)
```

`lesson03_tally.py`：
```python
err = math.sqrt(sq/(N-1)/N - mean**2/(N-1))
```

用笔推一遍，你会确认这两个式子**在实数意义下完全相等**。

**但浮点数不是实数。** 加减乘除的**结合顺序变了，结果的最后一两个二进制位就可能变。**

所以 `mean_se` 只能挑一种写法，那么**另一个文件的输出就可能在最后一位上变**。

### 遇到这种情况怎么办 —— 这才是本节的重点

**先别急着回退，也别急着说"没事，是浮点误差"。** 按顺序做三件事：

1. **看变了多少。** `git diff` 会指出是哪一行哪个数。算一下相对变化 `|新−旧|/|旧|`。
   - **~1e-16 量级** → 是重结合，正常。
   - **1e-9 或更大** → **不是浮点，是你写错了公式。** 回去查。
2. **确认变的位置符合预期。** 重结合的误差应该出现在**打印精度的最后一位**（`%.6f` 就是第 6 位小数，`%.2e` 就是第 2 位有效数字）。要是变在第 3 位，那不是浮点。
3. **确认没有 assert 炸。** 判据都是 3σ 级的，而 3σ ≈ 1e-3 相对量级，比 1e-16 大十三个数量级 —— **重结合绝不可能让任何一条 assert 状态翻转。要是翻转了，一定是别的东西错了。**

> **判据修正**：「输出逐位不变」这条要求对 lesson04 严格成立（因为 `mean_se` 照它的写法抄）。
> 对 lesson03，**允许最后一位有差异，但你必须能说出上面 1、2、3 三条各自的结论**，说不出就不算过。
>
> 这不是放宽标准。**这是在教你区分「我改坏了」和「浮点重结合」** —— 12 月你把这套东西翻成 C++，编译器开 `-O2` 之后到处都是重结合，那时候你每天都要做这个判断。

**所以 `mean_se` 抄哪一种？** 抄 lesson04 那种（`N/(N-1)*(sq/N - mean**2)`）。理由：它把「贝塞尔修正」写成了一个独立可见的因子 `N/(N-1)`，读代码的人一眼看得见修正在哪；lesson03 那种把修正拆进了两项，看不出来。**可读性在两个都对的写法之间是唯一的裁决标准。**

## 5. 模块必须有的两样东西

### 5.1 `if __name__ == "__main__":` 自测块

```python
if __name__ == "__main__":
    # 只有直接 python mcstat.py 才跑；被 import 时不跑
    ...
```

**为什么必须有这个 guard**：不加的话，`import mcstat` 会**执行模块顶层的所有语句**，你的自测输出会混进 lesson03 的输出里，diff 立刻脏。

自测块里放 **2 条**（不是 5 条，这个模块本身很薄）：

- **一条恒等式级的**（1e-12）：给一组你手算得出答案的小数据（比如 `x = [1,2,3,4]`，`n=4`），检查 `mean_se` 返回的 `var` 等于手算值。**手算一遍，别用另一段代码算 —— 那样两边同源，就是 9/2 那个恒真 assert。**
- **一条抓 `chi2_uniform` 的**：构造一组**完全均匀**的 counts（每箱一样多），卡方必须**精确为 0**。

每条旁边写一行「这条抓什么」。写不出就删。

### 5.2 每个函数一行 docstring

```python
def mean_se(s, sq, n):
    """由 Σx、Σx²、n 算样本均值、贝塞尔方差、均值标准误。"""
```

docstring 是你零覆盖清单上的一项。写一行就够，别写成小作文。
