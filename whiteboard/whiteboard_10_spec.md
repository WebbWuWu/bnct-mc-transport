## 0. 这道题在说什么（先读懂，再做题）

### 0.1 你现在的程序怎么处理碰撞

`lesson03_tally.py` 里，中子每撞一次，就抽一个随机数决定死活：

```python
if rng.random() < sigma_s/sigma_t:      # 散射：换个方向，接着飞
    u,v,w = isotropic_direction(rng)
    ...
else:                                   # 吸收：这条历史到此结束
    n_A += 1
    ...
    break
```

这种做法叫**类比**（analog）：程序里每件事发生的概率 = 物理上真实发生的概率。

### 0.2 这道题要换成的做法：隐式俘获

**中子永远不会在碰撞里死掉。** 每撞一次：

```
wt = wt × (Σs/Σt)      # 权重打个折
然后必定散射，接着飞
```

源中子出生时 `wt = 1.0`。打分也要把权重考虑进去 —— 具体怎么改，是 (3) 让你写的。

**直观理解**（设 Σs/Σt = 0.8）：
类比里，100 个中子各撞一次，大约 80 个活下来、20 个死掉。
隐式里，1 个中子撞一次**一定**还活着，只是它从「代表 1 个中子」变成「代表 0.8 个中子」。

### 0.3 记号表

| 记号 | 意思 | 例子 |
|---|---|---|
| `p` | `Σs/Σt`，一次碰撞后活下来的概率 | 0.8 |
| `wt` | **权重**：这个模拟粒子代表多少个真实中子 | 出生时 1.0，撞一次后 0.8 |
| `w` | **方向余弦**（方向的 z 分量），和权重无关 | `z1 = z0 + s*w` 里那个 |
| `E[X]` | X 的期望 = 同样的事重复无数次，取平均 | — |
| `S` | 见 0.4 | — |

🔴 **`wt` 和 `w` 是两个东西，写混了要扣分。**

### 0.4 `S` 是什么

把时间停在**某一次碰撞刚结束**的那一刻。
假设中子**活着、带着权重 1** 从这里接着飞，一直飞到这条历史结束（从板子左边或右边飞出去）。
这一段里它往 `track_h` 上**还会加的**所有分数之和，叫 `S`。这一刻之前已经加上的，不算。

之后飞多远、往哪拐，全靠还没抽出来的随机数，所以 `S` 每次都不一样，是一个**随机变量**。
从同一个起点重跑无数次，`S` 的平均值就是 `E[S]`。

**为什么要引入 S**：碰撞之后的事太复杂（还要飞很多段、撞很多次），一段一段写不完。
把「之后的全部」打包成一个 `S`，(1) 就只用 `p` 和 `E[S]` 两个量写得出来。

## (2) 方差：在一个简化模型上算数字　【1.5 分】（约 5 分钟）

**简化模型**：不管几何、不管飞多远，只问一件事 ——
**「一个中子连着撞 10 次，最后还剩多少？」** 这个「还剩多少」就是得分 `X`。取 `p = 0.8`。

- **类比**：每撞一次都抽一次死活。10 次全活下来 → `X = 1`；中途死了 → `X = 0`。
- **隐式**：永远不死，每撞一次权重乘 `p`。撞完 10 次，`X` 就是剩下的权重。

要用到的工具：

| 工具 | 内容 | 在哪学的 |
|---|---|---|
| 指示变量 | 只取 0 或 1、取 1 的概率是 P 的量：均值 = P，方差 = P(1−P) | 白板题④ |
| 标准差 `s` | `s = √方差`，**单条历史**的得分散得多开 | 第 4 课 |
| 标准误 `SE` | `SE = s/√N`，N 条历史**取平均之后**，平均值的误差 | 第 4 课 |
| 相对误差 `R` | `R = SE / 平均值` | 白板题⑨ |
| 一个数 | `0.8¹⁰ ≈ 0.1074` | — |

⚠️ `s`（单条的散布）和 `SE`（平均值的误差）你混过两次，这一问别混。

- **(2a)** 类比：`X` 的期望、方差各是多少？给三位有效数字。
- **(2b)** 隐式：`X` 的期望、方差各是多少？
- **(2c)** 类比要跑多少条历史 `N`，才能让 `R` 降到 5%？**先写式子，再代数字。**
- **(2d)** 真实程序里，隐式做法的方差**不会**等于 (2b) 算出来的值。
  **这个模型拿掉了什么？** 至少说出一样「真实程序里仍然是随机的、但模型里被拿掉了」的东西。

## (6) GPU 上的代价　【0.5 分】（约 2 分钟）

**背景**：GPU 把 32 个线程编成一组（warp），一起一步一步往前走。每个线程跑一条历史。
组里有的线程早跑完了，也得**等组里最慢的那个**，这一组才算完。

- 类比：每条历史什么时候结束是随机的，有的第一次碰撞就被吸收了，有的要撞很多次。
- 隐式：没有吸收。历史只会因为飞出板子，或者被你主动截断而结束。

- **(6a)** 同一个 warp 里，32 条历史「结束得参差不齐」的情况，哪种做法更严重？为什么？
- **(6b)** 估一个 warp 要花多长时间，该用 32 条历史的**平均**长度，还是**最长**那条的长度？一句话。

⚠️ 只答「会不会发散」不得分，要说清楚代价往哪边变。
