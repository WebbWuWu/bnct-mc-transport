## 2. 类比（analog）与非类比（non-analog）

**类比蒙卡**：程序里发生的每一件事，都按它在物理上真实发生的概率发生。
你现在的 `lesson03_tally.py` 就是纯类比的：

```
掷一个随机数 ξ
ξ < Σs/Σt  →  散射，粒子继续
否则       →  吸收，粒子当场死掉，这条历史结束
```

**非类比蒙卡**：故意**不按**真实概率抽样，然后用**权重**把偏差补回来。

> **非类比方法的全部套路只有一句话**：
> **改变"事件发生的概率"，同时改变"事件发生时记多少分"，让两者的乘积保持不变。**
>
> 隐式俘获、源偏倚、分裂、轮盘赌（⑪）、指数变换，全是这一句话的不同用法。
> **记住这一句，以后每见到一个新的方差缩减方法，你只需要问：它改了哪个概率、用什么权重补回来。**

## 3. 隐式俘获（implicit capture）是什么

也叫**存活偏倚**（survival biasing）。它把上面那段换成：

```
粒子不再被吸收杀死。每次碰撞：
    wt  ←  wt × (Σs/Σt)          权重按"存活概率"打折
    粒子必定散射，继续飞
```

**打分也要跟着改。** 原来每段径迹记的是长度，现在记的是**权重 × 长度**：

```
类比：  track_h[k] += dz_step / |w|
隐式：  track_h[k] += wt * dz_step / |w|
```

源粒子出生时 `wt = 1.0`。

**直观理解**：类比里一个粒子撞了 3 次还活着的概率是 `(Σs/Σt)³`，要么活要么死。
隐式里这个粒子**一定**还在，只是它现在"只代表 `(Σs/Σt)³` 个中子"。

> **无偏性**（改了抽样却不改答案）**是规格书 (1) 要你证的，这里不给。**
> 给你证明要用的工具：写出「一次碰撞之后，对后续某个得分 `S` 的期望」，**两种做法各写一个式子，比较它们**。
> 类比那边是「以某概率拿到 `E[S]`，以另一概率拿到 0」；隐式那边是「必定拿到，但乘了一个系数」。

## 4. 为什么方差会小 —— 以及它省的到底是什么

**类比的问题**：一条历史对深层格子的贡献是**要么全有、要么全无**。
你第 3 课自己写下的那句话 ——「相对误差随深度单调增加，最深处最大，而这是最需要算准的区域」—— 描述的就是这件事。

**隐式做的事**：把"全有/全无"换成"每次都有一点，但每次少一点"。
**贡献不再是 Bernoulli 式的跳变，方差自然小。**

**§4 给你一个玩具模型**（规格书 §2 会让你在它上面算数字，这里只把模型说清楚，**不给数**）：

```
简化：忽略几何，只问「一个中子连续经历 n 次碰撞之后，还剩多少」
      令 p = Σs/Σt（单次碰撞的存活概率）

类比：得分 X 是指示变量 —— 以概率 p^n 得 1，以概率 1−p^n 得 0
隐式：得分 X 恒等于 p^n，一个随机性都没有
```

你要用的工具：**指示变量的方差 `Var = P(1−P)`**（白板题④ 拿到的），以及 `R = SE/x̄`。

> ⚠️ **这个玩具模型是理想化的**：真实程序里飞行距离和散射方向仍然是随机的，
> 所以隐式的方差**不会真的等于 0**，只是小得多。
> **规格书 §2 有一问就是在考「这个模型省略了什么」—— 别把玩具模型的结论直接当成真实结论。**
> （纪律：**任何一个查来的值，用之前先问它在什么条件下成立**，包括你自己刚推出来的。）

## 5. 天下没有白拿的方差 —— 三样代价

**① 历史变长了。** 类比里粒子会被吸收掉，历史自然结束；隐式里粒子**永远不死**，
只会权重越来越小。`wt = 0.8^n`，撞 100 次也只是 2e-10，**但它还在消耗 CPU。**
所以隐式俘获**必须**配一个权重下限和截断办法 —— 那就是**白板题⑪ 的轮盘赌**（9/24）。

**② 时间变长了，所以不能只比 `R`。** 方差小了但每条历史更贵，
**划不划算要看 FOM = 1/(R²·T)，不能只看 R 变小了多少。**（白板题⑨ §3 那条）

**③ 一批判据会失效。** 这一条最要紧，因为它**不报错**：

| 现在成立的 | 加了隐式俘获之后 |
|---|---|
| `T + R + A = 1`（三个计数除以 N） | `A` 不再是"被吸收的粒子个数"，它变成了**权重的累加** |
| 判据 5：散射 4 / 吸收 2 / 飞出 1 个随机数 | **"散射还是吸收"那个随机数不抽了** |
| 验证 B：`Σt·Σtrack − n_碰撞 = 0` | 径迹带权重、碰撞数不带 —— **等式两边不是同一个量了** |
| `n_stuck`（撞满 `Max` 判为异常） | 撞满 `Max` 会变成**常态**，不再是异常 |

> 🔴 **规格书 §5 就是问这四条各自会怎样。**
> **这一节是整道题里最值钱的部分** —— 它练的是 9/19 立的那条：
> **「判据的适用条件要和判据一起写下来」**，否则改一次抽样方式，你会以为是代码坏了。

## 6. GPU 上的一句话伏笔

类比里一条历史什么时候结束是随机的；隐式里**每条历史都活到你主动截断为止**。

**这件事对 warp 是好是坏，是规格书 (6) 要你判的。** 给你两个已有的参照：

- 9/16：「**会不会发散」和「代价有多大」是两个问题，只答第一个不得分**。
- 今天 (6c)：舍选法单线程平均 1.27 轮，32 线程 warp 要等 3.13 轮 —— **发散的代价要用"warp 里最慢的那个"去算，不是用平均值。**
