## 记号（先读）

| 记号 | 含义 |
|---|---|
| N | 历史数（这里 = 100000） |
| x_i | 第 i 条历史在第 1 层留下的径迹长度（cm） |
| S、Q | S = Σx_i，Q = Σx_i²（你的 json 里的 `track_sum[0]`、`track_sq[0]`） |
| x̄ | 样本均值 S / N |
| σ₁² | **单条历史**的方差：一条历史的 x 晃多大 |
| Var(x̄) | **均值 x̄** 的方差：重跑一次 N 条，x̄ 晃多大 |
| SE | 均值的标准误 = √Var(x̄) |
