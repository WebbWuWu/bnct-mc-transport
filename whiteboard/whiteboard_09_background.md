## 1. 五个量，五个名字（先把记号讲清）

设第 i 条历史的得分是 `x_i`，一共 N 条。

| 记号 | 读作 | 是什么 | N 变大时 |
|---|---|---|---|
| `σ²` | 总体方差 | **单条历史**得分的散布，是那个分布本身的性质 | **不变** |
| `s²` | 样本方差 | 用手里 N 个样本去**估** `σ²` | **不变**（只是估得越来越准） |
| `Var(x̄) = σ²/N` | 均值的方差 | 你交的那个 `x̄` 的散布 | `∝ 1/N` |
| `SE = s/√N` | 标准误 | 误差棒，`Var(x̄)` 开根号的估计 | `∝ 1/√N` |
| `R = SE / x̄` | 相对误差 | 误差棒占结果的比例，**无量纲** | `∝ 1/√N` |

> 🔴 **从 `s²` 走到 `Var(x̄)`，除以 N 这件事一共只发生一次。**
> 「SE 多除一次 N」就是让它发生了两次。

**`mean_se` 里 `n` 一共出现在四个地方，只有一个是「那一次除 N」**：

```python
mean = s/n                      # ① 算平均，不是「那一次」
var  = n/(n-1)*(sq/n - mean**2) # ② n/(n-1) 是贝塞尔（§2）  ③ sq/n 也是在算平均
se   = math.sqrt(var/n)         # ④ 这才是「那一次」：从 s² 走到 Var(x̄)
```

> 所以「数 `/n` 出现几次」这种办法**抓不住**多除一次 —— 合法的 `/n` 本来就有三个。
> 要抓它，得看**输出随 N 怎么变**（§3 那张表）。

## 2. 贝塞尔修正 `n/(n−1)` 从哪来

**记号**：「贝塞尔修正」就是 `mcstat` 里那个 `n/(n-1)`。

直觉：**真均值 `μ` 你不知道，只好用 `x̄` 代替。**
而 `x̄` 是从同一批数据里算出来的 —— 在所有候选的「中心」里，它恰好让 `Σ(x_i − 中心)²` 最小。
所以 `Σ(x_i − x̄)²` 比 `Σ(x_i − μ)²` **系统性地偏小**，平均偏小一个因子 `(n−1)/n`。乘回 `n/(n−1)` 就补上了。

**「自由度 n−1」是什么意思**：n 个偏差 `x_i − x̄` 加起来**恒等于 0**，
所以知道了其中 n−1 个，最后一个就被定死了。真正「自由」的只有 n−1 个。

**它什么时候要紧**：

| n | `n/(n−1)` | 对 SE 的影响 |
|---|---|---|
| 10⁶ | 1.000001 | 5×10⁻⁷（白板题④ 里那个「两条路差 5.000e-07」就是它） |
| 100 | 1.0101 | 0.5% |
| 10 | 1.111 | 5.4% |

> 🔴 **贝塞尔只在 n 小的时候要紧 —— 而 n 小正好是「分批」的情形（§4）。**

⚠️ `mcstat` 写的是 `n/(n-1)*(sq/n - mean**2)`，教科书写的是 `Σ(x_i − x̄)²/(n−1)`。
**这两个在代数上恒等**（把平方展开就能验），**但在浮点上不等** —— 见 §5。

## 3. 相对误差 R 和品质因数 FOM

**为什么要 R**：剂量的 SE 单位是 Gy，通量的 SE 单位是 cm⁻²，**没法放在一起比**。
`R = SE/x̄` 无量纲，谁都能比。

**FOM 的来路**（**FOM** = figure of merit，读「品质因数」）：

```
R ∝ 1/√N     ==>   R² ∝ 1/N
T ∝ N        （运行时间跟着历史数走）
==>  R² · T  跟 N 无关
FOM = 1 / (R² · T)          越大越好
```

**它量的是「每秒钟买到多少精度」**。同一个程序跑长跑短，FOM 不变（在统计涨落内） ——
所以 **FOM 是「程序 + 算法 + 机器」的性质，不是某一次运行的性质。**
这就是它能当加速比分母的原因。

### 一张真数字的表（你的 `lcg`，你的 `mean_se`）

量：飞行距离 `x = −ln(1−ξ)/Σt`，`Σt = 0.5 cm⁻¹`。**真值 `1/Σt = 2`，`σ² = 1/Σt² = 4`。**
seed = 20260921。**时间是在 Claude 的容器里测的（Linux，CPython），不是你的电脑。**

```
N        x̄         s²       SE         R          R·√N     偏差      T (s)    FOM
10⁴     1.99724   3.9935   1.998e-02  1.001e-02  1.0006   -0.14σ    0.007    1.5e6
10⁵     1.99982   4.0118   6.334e-03  3.167e-03  1.0016   -0.03σ    0.063    1.57e6
10⁶     1.99642   3.9825   1.996e-03  9.996e-04  0.9996   -1.79σ    0.695    1.44e6
```

**要从这张表里读出来的三件事：**

1. **`s²` 不随 N 变**（都在 4 附近），**SE 和 R 每乘 10 倍 N 缩 √10 ≈ 3.16 倍**。
2. **`R·√N` 是个常数**，而且就等于**单条历史的相对散布 `σ/μ`**。
   对指数分布 `σ = μ = 1/Σt`，所以这个常数是 1。（换一个量，常数就换，但**照样是常数**。）
3. **FOM 三行在 1.44–1.57×10⁶ 之间晃**，不是一个死数：
   `T` 只有 7 ms 那一行，计时本身就不准；`R` 自己也有误差（§4）。

⚠️ **FOM 不变的适用条件**（纪律 5：判据的适用条件要和判据一起写下来）：
- N 大到 `R ∝ 1/√N` 已经成立；
- **`T ∝ N`，也就是没有「固定开销」**。凡是每次运行开头都要做一遍、而且不随 N 变的事，都会破坏这一条。

## 4. 误差棒自己的误差

`s²` 是从样本算出来的，**所以它自己也是个随机量**。

**如果**被平均的那 n 个数近似服从正态分布，有一个现成结论：

```
s² 的相对标准差  ≈ √( 2/(n−1) )
s（开了根号）    ≈ 1/√( 2(n−1) )      <- 开根号，相对误差减半
```

| n | SE 自己的相对误差 |
|---|---|
| 10 | 23.6%（9/20 日志那个「1/√18 ≈ 24%」就是它） |
| 100 | 7.1% |
| 10⁶ | 0.07% |

⚠️ **适用条件：被平均的那 n 个数要近似正态。**
- **单条历史的得分**通常**不是**正态的（指数分布、0/1 分布都不是）→ 这条公式不能直接套。
- **批均值**（下面定义）由中心极限定理近似正态 → 可以套。

**「分批」是什么**：把 N 条历史切成 `n_b` 批，每批算一个均值，
然后把这 `n_b` 个批均值**当成样本**，喂进 `mean_se`。
Neudep 式 (1) 就是这么做的，`n_b ≈ 10`。

> 🔴 9/20 你第一次读反过一次：**分批是用来「估计」误差的，不是用来「减少」误差的。**

## 5. 浮点：两个很接近的大数相减

**记号**：`double` = Python 的 `float`，64 位；`float32` = 32 位，GPU 上常用（第 12–14 课要定用哪个）。

| | 有效数字 | 从哪开始连整数都存不全 |
|---|---|---|
| `double` | 约 15–16 位 | `2⁵³ ≈ 9.0×10¹⁵` |
| `float32` | 约 7 位 | `2²⁴ ≈ 1.7×10⁷` |

**越过那个界以后，相邻两个能存的数之间隔着不止 1**：

```python
>>> math.ulp(1e16)          # 1e16 附近，相邻两个 double 差 2
2.0
>>> (1e16 + 1.0) - 1e16
0.0
```

> 🔴 **那个 1 不是在减法里丢的，是在加法 `1e16 + 1.0` 那一步就已经丢了。**
> 减法本身是精确的 —— 它只是把前面丢掉的东西**暴露出来**。
> 两个很接近的大数相减，结果里剩下的几乎全是之前的舍入误差。这叫**灾难性抵消**（catastrophic cancellation）。

**什么时候会碰上**：凡是「先分别算两个大数，再相减得到一个小数」的式子。
规格书 (5) 会让你在自己的代码里找这样的式子。
