## 记号（先读）

| 记号 | 意思 |
|---|---|
| `x_i` | 第 i 条历史的**得分**（这一题里是某一层的径迹长度，cm） |
| `N` | 历史数 |
| `x̄` | 样本均值 = 所有 `x_i` 的平均，就是我们报出去的那个估计值 |
| `σ₁²` | **单条历史**得分的方差（一条历史的分数散得有多开） |
| `Var(x̄)` | **均值** `x̄` 这个估计量的方差（重跑整个模拟 N 条历史，`x̄` 会晃多少） |
| `SE` | 标准误 = `x̄` 的误差棒 |
| `p̂` | 「命中」历史的比例（命中记 1、没命中记 0 时的 `x̄`） |

## 一、两个「Var」　【2.0 分，约 15 分钟】

某次运行 `N = 40000` 条历史，第 3 层每条历史的径迹长度 `x_i`，累加得：

```
Σx  = 18372.6   cm
Σx² = 29815.4   cm²
```

**(1a)** 依次写出 **`x̄`、`σ₁²`（带贝塞尔修正）、`Var(x̄)`、`SE`** 四个量：**每个先写公式、再算数值**（保留 4 位有效数字）。【0.8】

**(1b)** `mcstat.mean_se` 返回的三个值里，叫 `var` 的那个，是 (1a) 四个量中的哪一个？`se` 呢？**用一句话说出 `σ₁²` 和 `Var(x̄)` 差在哪**（不许只写公式，要说出物理意思）。【0.4】

**(1c)** 同一次运行里，`N = 40000` 条历史中有 9137 条在板内被吸收。把「被吸收记 1、没被吸收记 0」当成每条历史的得分。
　　写出 `p̂`、这个 0/1 得分的 `σ₁²`、以及 `SE(p̂)`，算出数值。
　　然后回答：如果有人写成 **`SE = √( Var(p̂) / N )`**，会得到多少？和正确值差几倍？这个倍数是从哪来的？【0.5】

**(1d)** 想让第 3 层的 SE 降到 (1a) 那个值的 **1/3**，`N` 至少要多少？写出你是怎么推的。【0.3】
