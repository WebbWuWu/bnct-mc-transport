## 0. 这道题在说什么（先读懂，再做题）

### 0.1 你已经有的程序

`lesson03_tally.py` 的 `run_slab` 就是这个问题：一块厚 `d` 的平板，中子从左表面 `z = 0` **垂直射入**（方向余弦 `w = 1`），一直追到它透射（`z > d`）、反射（`z < 0`）或被吸收。透射率

```
T̂ = n_T / N        （透射个数 / 历史数）
```

`T̂` 头上的帽子表示「蒙卡估出来的值」，和真值 `T` 区分开。

**纯吸收**时（`Σs = 0`）有一个解析解：

```
T = exp(−Σt · d)
```

这道题问三件事：**这个式子怎么来的、蒙卡结果和它差多少算对、它在什么条件下才成立。**

### 0.2 记号表

| 记号 | 意思 | 本题的值 / 例子 |
|---|---|---|
| `Σt` | 总宏观截面，单位 cm⁻¹ | 1.0 cm⁻¹ |
| `Σs`、`Σa` | 散射、吸收截面，`Σt = Σs + Σa` | — |
| `d` | 板厚 | 2.0 cm |
| `s` | 一次飞行的距离，`s = −ln(1−ξ)/Σt` | — |
| `ξ` | 均匀分布在 `[0,1)` 上的随机数 | `rng.random()` |
| `w` | **方向余弦**（方向的 z 分量） | 垂直入射时 1.0 |
| `N` | **历史数**（跑了多少个中子），不是碰撞次数 | 20000 |
| `T` | 透射率的**真值** | — |
| `T̂` | 透射率的**蒙卡估计** | — |
| `s`（统计） | ⚠️ 本题**不用**这个字母表示标准差，避免和飞行距离 `s` 撞名。标准差写成 `σ₁`（单条历史） | — |
| `SE` | 标准误 = `σ₁/√N`（N 条取平均后的误差） | — |

🔴 **一个名字装两样东西**你已经犯过 4 次（最近一次：`N` 历史数当碰撞次数）。本题特意把「标准差」改名叫 `σ₁`，因为 `s` 已经是飞行距离了。

### 0.3 要用到的工具

| 工具 | 内容 | 在哪学的 |
|---|---|---|
| 地基 | 均匀分布落在某个区间里的概率 = 那个区间的长度 | 9/16，四个抽样方法共用 |
| 指示变量 | 只取 0 或 1，取 1 的概率是 P：均值 P，方差 P(1−P) | 白板题④ |
| 标准误 | `SE = σ₁/√N` | 第 4 课 |
| 偏离几个 σ | `dev = (T̂ − T) / SE`，`mcstat.dev_sigma` 做的就是这个 | 第 4 课 |
| 一个数 | `e⁻² = 0.13534` | — |

## (1) 推导：为什么纯吸收时 `T = exp(−Σt·d)`　【1.5 分】（约 5 分钟）

纯吸收、垂直入射：中子第一次碰撞就被吸收。所以「透射」等价于「第一次飞行的距离 `s` 就超过了 `d`」。

- **(1a)** 把「`s > d`」这件事，改写成「`ξ` 落在某个区间里」。一步一步写：从 `−ln(1−ξ)/Σt > d` 出发，每一步变形写一行，最后得到 `ξ > ?`。
  ⚠️ 两边同乘或取对数时，**不等号方向变不变**，每一步都要看一眼。
- **(1b)** 用地基那条性质，写出这个区间的概率，化简到 `exp(−Σt·d)`。
- **(1c)** 这个推导**用到了**「垂直入射 `w = 1`」吗？用在了哪一步？（(5) 会接着问。）

## (2) 算数字：差多少算对　【1.5 分】（约 6 分钟）

取 `Σt = 1.0`、`d = 2.0`、纯吸收，`N = 20000`。某次跑出 `T̂ = 0.1380`。

- **(2a)** 真值 `T` 是多少？（四位有效数字）
- **(2b)** 单条历史的得分是一个指示变量（透射记 1，否则记 0）。用 `T̂` 算它的标准差 `σ₁`，再算 `SE`。
- **(2c)** `T̂` 离真值差几个 `SE`？按 3σ 判据，算过还是不过？
- **(2d)** 学习路线图写的目标是「和解析解对拍到 **3 位有效数字**」，也就是要 `3·SE < 0.0005`。
  `N` 至少要多少？**先写式子，再代数字。**（`T(1−T)` 用真值 `T` 算。）
  然后一句话：这个 `N` 和你平时跑的 2 万比，差几倍？

⚠️ `σ₁`（单条历史散得多开）和 `SE`（平均值的误差）别混。
