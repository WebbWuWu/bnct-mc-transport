## 0. 这道题在说什么（先读懂，再做题）

### 0.1 接着⑩ 往下：隐式俘获留下的问题

⑩ 里换成了隐式俘获：中子永远不在碰撞里死掉，每撞一次权重打个折：

```
wt = wt × (Σs/Σt)
```

打分时权重乘在分数上（⑩ (3) 订正过的那一行）：

```python
track_h[k] += wt * dz_step / abs(w)
```

问题：权重只会越来越小，永远不会变成 0。取 `Σs/Σt = 0.8`：

| 撞了几次 | 0 | 10 | 30 | 100 |
|---|---|---|---|---|
| `wt = 0.8^n` | 1.0 | 0.107 | 0.00124 | 2.0e-10 |

撞了 100 次的中子，每飞一段只往 `track_h` 上加 `2e-10 × 路程`，对答案几乎没有贡献，**但算它一段所花的 CPU 时间和 `wt = 1` 的中子一样多。**
所以要有一个办法，把这种「几乎不贡献、但还在花时间」的中子处理掉。

### 0.2 轮盘赌：规则

定两个常数：**阈值 `W_c`** 和 **幸存权重 `W_s`**（本题取 `W_c = 0.25`，`W_s = 0.5`）。

每次碰撞、权重打完折之后，检查一次：

```
如果 wt >= W_c：   什么都不做，接着飞
如果 wt <  W_c：   玩一次轮盘赌：
                     以概率 q = wt / W_s  活下来，权重改成 W_s，接着飞
                     以概率 1 − q          死掉，这条历史到此结束
```

**算例**（这不是 (2) 的数，(2) 用别的数）：某次碰撞后 `wt = 0.2`，小于 `W_c = 0.25`，要玩。

```
q = wt / W_s = 0.2 / 0.5 = 0.4
抽一个随机数 ξ（均匀分布在 [0,1)）：
  ξ = 0.13  →  0.13 < 0.4  →  活下来，wt 从 0.2 变成 0.5，接着飞
  ξ = 0.71  →  0.71 ≥ 0.4  →  死掉，这条历史结束
```

**直观理解**：100 个 `wt = 0.2` 的中子来玩，大约 40 个活下来、各带 0.5，60 个死掉。
活下来的 40 × 0.5 = 20，和玩之前的 100 × 0.2 = 20 一样多。
**要跟踪的中子从 100 个变成 40 个，总权重平均不变。** 这就是它省时间的地方。

### 0.3 记号表

| 记号 | 意思 | 本题的值 / 例子 |
|---|---|---|
| `wt` | **权重**：这个模拟粒子代表多少个真实中子 | 出生 1.0 |
| `w` | **方向余弦**（方向的 z 分量），和权重无关 | `z1 = z0 + s*w` 里那个 |
| `W_c` | 阈值：权重低于它才玩轮盘赌 | 0.25 |
| `W_s` | 幸存权重：赢了之后权重改成它 | 0.5 |
| `q` | 活下来的概率，`q = wt / W_s` | 上面算例里 0.4 |
| `ξ` | 一个均匀分布在 `[0,1)` 上的随机数 | `rng.random()` 给的那个 |
| `wt_new` | 玩完轮盘赌之后的权重（死了算 0） | 0.5 或 0 |
| `S` | 见 0.4（和⑩ 的 `S` 是同一个东西） | — |
| `E[X]` | X 的期望 = 同样的事重复无数次，取平均 | — |

🔴 **`wt` 和 `w` 是两个东西；`W_c`、`W_s` 是常数，`wt` 是变量。写混了要扣分。**

### 0.4 `S`，以及「得分和权重成正比」

`S` 的定义和⑩ 一样：把时间停在**轮盘赌刚要开始**的那一刻，假设中子**带着权重 1** 从这里接着飞到历史结束，这一段里它往 `track_h` 上**还会加的**分数之和。这一刻之前已经加上的不算。`S` 是随机变量，平均值是 `E[S]`。

**得分和权重成正比**，这一点 (1) 要用，先用数字看清楚：

同一条路径（飞过第 3 层 `dz_step/|w| = 2.0`，再飞过第 4 层 `dz_step/|w| = 1.0`）：

| 权重 | 第 3 层加 | 第 4 层加 | 这一段合计 |
|---|---|---|---|
| 1.0 | 1.0 × 2.0 = 2.0 | 1.0 × 1.0 = 1.0 | 3.0 |
| 0.5 | 0.5 × 2.0 = 1.0 | 0.5 × 1.0 = 0.5 | 1.5 |

每一次打分都是 `wt × 路程`，所以整段加起来也是 `wt × (权重为 1 时的合计)`。
⟹ **带着权重 `wt` 接着飞，之后还会拿的分数 = `wt × S`。**

⚠️ 这条只在**飞行途中权重不变**时成立。碰撞时权重会再打折，但那是 `S` 里面的事：`S` 已经把「权重为 1 出发、之后照常打折」全包进去了。

## (2) 算数字：一个中子玩一次　【1.5 分】（约 5 分钟）

取 `W_s = 0.5`。某中子碰撞后 `wt = 0.1`，小于 `W_c`，要玩。

要用到的工具：

| 工具 | 内容 | 在哪学的 |
|---|---|---|
| 指示变量 | 只取 0 或 1、取 1 的概率是 P：均值 = P，方差 = P(1−P) | 白板题④ |
| 🆕 **乘一个常数** | `Var(c·X) = c² · Var(X)`，均值是 `c · E[X]` | 见下面算例 |
| 标准差 `s` | `s = √方差`，**单个粒子**的值散得多开 | 第 4 课 |

**🆕 `Var(c·X) = c²·Var(X)` 的算例**（为什么是 c² 不是 c）：

```
X 是指示变量，P = 0.5：  X 取 0 或 1，均值 0.5，方差 0.5 × 0.5 = 0.25
令 Y = 2X：              Y 取 0 或 2，均值 1.0
Y 的方差 = 各值离均值的距离平方，按概率加权：
         = 0.5 × (0 − 1.0)² + 0.5 × (2 − 1.0)²
         = 0.5 × 1 + 0.5 × 1 = 1.0
而 2² × 0.25 = 1.0   ✓   （距离放大 2 倍，距离的平方放大 4 倍）
```

⚠️ 这一问全部是**单个粒子**的 `wt_new`，用的是 `s`，不是 `SE`。`SE = s/√N` 是 N 个取平均之后的误差，这一问用不到。

- **(2a)** 加轮盘赌：`q` 是多少？`wt_new` 的均值、方差、标准差 `s` 各是多少？
  提示：`wt_new = W_s × (一个指示变量)`。这个指示变量取 1 的概率是多少？
- **(2b)** 不加轮盘赌：`wt_new` 就是 `wt` 本身。均值、方差各是多少？
- **(2c)** 1000 个 `wt = 0.1` 的中子都来玩一次。平均活下来几个？玩之前总权重多少？玩之后总权重平均多少？
- **(2d)** 对比 (2a) 和 (2b)：**轮盘赌让方差变大了还是变小了？** 那为什么还要用它？
  用 `FOM = 1/(R²·T)` 回答（`R` 相对误差，`T` 计算时间，白板题⑨）：**`R` 和 `T` 各往哪边变，一句话。**
