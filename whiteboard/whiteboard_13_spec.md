## 0. 这道题在说什么（先读懂，再做题）

### 0.1 两个参考系

中子撞上一个**静止**的靶核（质量是中子的 `A` 倍），弹性散射。同一次碰撞，可以站在两个地方看：

| 参考系 | 站在哪看 | 这里看到的散射 |
|---|---|---|
| **LAB**（实验室系） | 站在地面上，靶核碰撞前不动 | 中子偏一个角度、**速率变小**，这是程序真正要的 |
| **CM**（质心系） | 跟着两者的质心一起走 | 中子**只转方向、速率不变**。低能时方向是各向同性的，最好抽 |

程序的做法是：**在 CM 里抽方向（好抽），再换算回 LAB（要用的）。** 第 4 课 `lesson04_energy.py` 的 `scatter` 做的就是这件事，第 7 课 §4.3 还要用到它的矢量版。

### 0.2 记号表

| 记号 | 意思 | 例子 |
|---|---|---|
| `A` | 靶核质量 / 中子质量 | H-1 取 1，O-16 手算取 16 |
| `v` | 碰撞前中子在 LAB 的**速率** | — |
| `V_cm` | 质心的速率 | — |
| `v_c` | 中子在 CM 里的速率（碰撞前后**相同**） | — |
| `μ_cm` | CM 里的散射角余弦，**范围 [−1, 1]** | 各向同性时在 [−1,1] 上均匀 |
| `μ_lab` | LAB 里的散射角余弦（相对**原飞行方向**），范围 [−1, 1] | — |
| `φ` | 绕原飞行方向转的方位角，**范围 [0, 2π)** | — |
| `w` | **方向余弦**：新方向的 z 分量（相对**z 轴**，不是相对原方向） | — |
| `E`、`E'` | 碰撞前、后中子在 LAB 的动能，`E ∝ v²` | — |
| `α` | `((A−1)/(A+1))²`，E'/E 的最小值 | H-1：0 |

🔴 你混过两对：**`μ` 的范围 [−1,1] vs `φ` 的范围 [0,2π)**；**`μ_lab`（相对原方向）vs `w`（相对 z 轴）**。本题 (4c) 专门考第二对。

### 0.3 要用到的工具

**① 动量守恒给出质心速度**：质量 1、速率 `v` 的中子，加上质量 `A`、静止的靶核，总动量 `1·v + A·0`，总质量 `1 + A`：

```
V_cm = 总动量 / 总质量 = v / (A+1)
```

**② 两个向量相加，合成长度的平方（余弦定理）**：长度 `a`、`b`，夹角余弦 `c`：

```
|合成|² = a² + b² + 2·a·b·c
```

算例：`a = 3`、`b = 4`、夹角 90°（`c = 0`）：`9 + 16 + 0 = 25`，合成长度 5 ✓。
夹角 0°（`c = 1`，同向）：`9 + 16 + 24 = 49`，长度 7 = 3 + 4 ✓。
夹角 180°（`c = −1`，反向）：`9 + 16 − 24 = 1`，长度 1 = 4 − 3 ✓。

**③ 反推**：LAB 里的速度 = 质心速度 + CM 里的速度，两个向量相加。
